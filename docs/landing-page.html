Quick 60-Second Installation

  1. Download the release zip: Click the Download button above to grab the official site-checkup-pro.zip.
  2. Upload to WordPress: Go to your WordPress admin and open Plugins → Add New → Upload Plugin.
  3. Install & Activate: Select the zip file, click Install Now, and then click Activate Plugin.
  4. Run your check-up: Open the new Site Checkup menu in your dashboard and click Run All Safe Tasks.
